# 🛠️ Troubleshooting & Network Tools

Repositório com guias práticos de diagnóstico e troubleshooting de redes e serviços, voltado para equipes de suporte e operação de telecomunicações.

---

## 📂 Conteúdo do Repositório

| Arquivo | Descrição |
|---|---|
| [tshoot_network.md](./tshoot_network.md) | Comandos e ferramentas de troubleshooting de rede (Ping, Tracert, Nslookup, MTR, CURL, Nmap, BGP, Looking Glass e outros) |
| [tshoot_iptv_claro-box.md](./tshoot_iptv_claro-box.md) | Roteiro de troubleshooting para IPTV VAS e IPTV GPON com Claro Box (GPON, STB, multicast/unicast) |
| [tshoot_netfone_gpon.md](./tshoot_netfone_gpon.md) | Roteiro de troubleshooting para NetFone GPON (registro SIP, ACS TR-069, DNS, OLT) |
